# 🛡️ Secure Scanner

An Enterprise-Grade, standalone desktop application for real-time password entropy analysis and live breach detection. 

## ✨ Features
* **Modern Dark UI:** Built with `CustomTkinter` for a sleek, responsive, and professional interface.
* **Advanced Entropy Scoring:** Integrates `zxcvbn` to calculate realistic crack times and evaluate credential strength.
* **Live Breach Intelligence:** Communicates securely with the 'Have I Been Pwned' API to detect compromised credentials in real-time using k-Anonymity.
* **Thread-Safe Architecture:** Utilizes multithreading to ensure the GUI remains completely responsive during network calls.

## 🚀 Installation & Setup Guide

Follow these simple steps to set up and run the application on your local machine.

### Prerequisites
Ensure you have [Python 3.x](https://www.python.org/downloads/) installed on your system.

### Step-by-Step Installation

**1. Open a terminal in the project directory.**

**Import** : https://github.com/Pratap-VSK/CyberSecurity_Password_Analyz.git

**2. Create a Virtual Environment**
It is highly recommended to isolate the project dependencies using a virtual environment:
```bash
python -m venv venv

.\venv\Scripts\Activate   :: for windows

source venv/bin/activate  :: for macOS/Linux-->

pip install -r requrements.txt  :: Install Dependencies

python app.py  :: Enter In your terminal and run

```
